# Multi-Section Video Looper
This Chrome extension allows users to loop multiple specific sections of a video. Users can define start and end times for each section they want to loop, and the extension will handle the looping.

## Background
The idea for this extension came from the need to repeatedly watch specific parts of a video, while current video looper extensions only allow looping a single section. This extension aims to provide more flexibility and convenience for users who want to loop multiple sections of a video.

## Features
- Loop multiple sections of a video simultaneously
- User-friendly interface for defining loop points
- Support for various video platforms

## Tech Stack
- HTML/CSS for the user interface
- JavaScript for the extension's functionality
- Chrome Extension APIs for interacting with the browser and video elements
